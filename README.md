# FastAPI Enterprise Clean Architecture

FastAPI backend loyihasi (.NET Core dasturchilari uchun Clean Architecture andozasida).

## Imkoniyatlar
- **Clean Architecture:** Domain, Schemas, Services, API qatlamlari
- **PostgreSQL & Asinxron SQLAlchemy 2.0:** AsyncSession bilan ma'lumotlar bazasi
- **Alembic:** Ma'lumotlar bazasi migratsiyalari (`dotnet ef migrations` muqobili)
- **Enterprise Autentifikatsiya:** JWT Access & Refresh tokenlar, bcrypt parollarni xeshlash
- **CORS Middleware:** React / Vite frontend bilan to'liq integratsiya
